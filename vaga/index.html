Não. A estrutura foi construída para quem está começando do zero. O aplicativo guia cada passo e a comunidade está sempre disponível para dúvidas.

É o grupo avançado do Google Cash — para quem já tem clientes e quer escalar para uma agência própria (R$10K–R$100K/mês). O acesso é liberado conforme você avança.
